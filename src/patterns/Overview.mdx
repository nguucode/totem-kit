# Patterns

Full sections/screens assembled from Components (atomic design's
"organisms"). Each pattern lives in `src/patterns/<category>/`, story set
to `Patterns/<Category>/<Pattern>`.

| Category | Typical patterns |
| --- | --- |
| **Marketing** | Hero, header/nav, feature sections, pricing, testimonials, CTA sections, footers |
| **Application UI** | Dashboards, page headings, stats, data tables, forms, settings screens, app navigation |
| **E-commerce** | Product overviews/lists, category filters, shopping cart, checkout, order history, reviews |

Nothing built yet — patterns get assembled from Components once enough of
those exist, and refined against the Figma designs when they land.
