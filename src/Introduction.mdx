# Totem Kit

**Early stage, not production-ready.** Only two components exist so far
(Button, Text Input — see **Components**), the color palette is still
a placeholder (no Figma tokens applied yet), and nothing here has had a
design review beyond the contrast measurements in the docs. Expect breaking changes on any `0.x` version bump.

Fine to poke around, install, or reference the setup (registry + npm
package); not ready to build a real product on top of yet.

See [the repo README](https://github.com/nguucode/totem-kit) for the stack,
folder structure, and how to consume a component.
