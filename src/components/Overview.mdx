# Molecules — Components

Single, reusable UI components. Reference list: [uiguideline.com/components](https://www.uiguideline.com/components).

Each component lives in `src/components/<category>/`, with its story set to
`Molecules/<Category>/<Component>`. Categories below — add a component to the
one it fits, or propose a new category if none fit.

| Category | Components |
| --- | --- |
| **Actions** | Button ✅, Toggle Button, Link |
| **Inputs** | Text Input, Textarea, Number Input, Select, Combobox, Checkbox, Radio, Switch, Slider, Date Picker, Color Picker, File Uploader, Search |
| **Feedback** | Alert, Inline Alert, Toast, Badge, Tag, Progress Bar, Skeleton, Spinner, Rating, Empty State, Error State, Success State |
| **Navigation** | Breadcrumbs, Tabs, Pagination, Sidebar, Menu, Stepper |
| **Overlay** | Modal, Popover, Tooltip |
| **Disclosure** | Accordion, Collapse |
| **Data Display** | Table, Card, Avatar, Divider, Carousel, Calendar |

Unchecked = not built yet.
